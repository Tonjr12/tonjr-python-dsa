# 🐍 Python para Dados e IA — Data Science Academy (DSA)

Repositório dedicado aos projetos práticos, exercícios e aplicações desenvolvidos durante a formação **Fundamentos de Linguagem Python (do Básico a Aplicações de IA)** pela Data Science Academy.

## 🎯 Foco Técnico
- Manipulação, estruturação e preparação de dados com Python
- Lógica de programação, estruturas de dados, funções e boas práticas
- Desenvolvimento de aplicações interativas de dados (Streamlit)
- Base técnica para **Banco de Dados**, **SQL** e **Data Science (FIAP)**

## 🚀 Projetos em Destaque
- **Simulador de Saque (`app_saque.py`)** e **Jokenpô (`app_jokenpo.py`)**: aplicações interativas construídas em Python e publicadas na Streamlit Community Cloud.
